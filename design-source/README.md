# Design source (reference only)

The original Claude Design prototype this app was built from. Nothing here is
imported, bundled or deployed — it is excluded from TypeScript, ESLint and
Prettier.

| File | What it is |
| --- | --- |
| `Daniel Portfolio.dc.html` | Source of truth for the public site |
| `CMS.dc.html` | Source of truth for the CMS UI |
| `portfolio-cms.js` | Content model: `DEFAULTS`, `SCHEMA`, `THEMES` |
| `support.js` | Prototype runtime (not shipped) |
| `Daniel Portfolio (pre-CMS backup).dc.html` | Earlier revision, for checking original details |
| `uploads/`, `screenshots/` | Reference images |
| `vercel.json`, `cms/index.html` | Prototype routing, superseded by the Next.js router |
